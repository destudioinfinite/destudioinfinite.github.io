Privacy Policy – YouTube MCP

Last updated: 26 November 2026

YouTube MCP is a personal tool used only by the owner of the Infinite Studio YouTube channel.

What data it accesses

With the owner's permission, it uses the YouTube Data API and YouTube Analytics API to read and manage the owner's own channel: videos, playlists, comments, captions and analytics.

How data is stored

Sign-in tokens and any data retrieved are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube MCP uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/connections.
